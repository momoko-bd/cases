# 本人訴訟×公共訴訟 ケースアーカイブ

本人訴訟のまま公共訴訟（社会の仕組みを問う訴訟）を担う個人を、当事者の語りと一次資料で記録するアーカイブです。
運営は、当事者として本人訴訟を争いながら発信を続ける大橋桃子が行います。

## このアーカイブについて

- お金（寄付・クラウドファンディング）も、法律相談・法的助言も扱いません。記録と公開に専念します
- ケースは当事者本人の同意のもと、本人の言葉と一次資料へのリンクで構成します
- 集まったケースは分類・可視化し、分野や争点の傾向を発信します
